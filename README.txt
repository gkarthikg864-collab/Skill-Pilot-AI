SkillPilot AI — V8 Learning Roadmap Update

This build keeps the working V7 login, agents, mentor, quiz and coding lab and adds the requested My Learning flow.

MY LEARNING
- Today's roadmap now has clickable topics 1–6.
- Clicking a topic opens a learning lesson with:
  * definition
  * how to use it
  * example
  * key equation/pattern
  * practice task
- Each topic has its own focus duration (20–45 minutes).
- Focus timer supports Start, Pause, Reset and Mark topic complete.
- Progress is calculated from completed roadmap topics, coding submissions and quiz sets.
- The selected learning topic is saved to the account.
- AI Quiz follows the selected learning topic and uses topic-specific questions.
- Coding Lab follows the selected learning topic and loads matching coding tasks.
- Completed topics are saved to the same account.
- Daily streak increments once per calendar day when the user signs in/opens the account. Refreshing the same day does not add another streak day.
- Coding submission no longer artificially increases the streak.

RUN
Use start_windows.bat and keep the terminal open for compiler/AI backend features.
